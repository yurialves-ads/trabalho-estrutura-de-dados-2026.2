## Exercícios

- 01 — Pesquisa Sequencial

## Como executar

É necessário ter o compilador GCC instalado.

### Exercício 01

```bash
gcc 01_pesquisa_sequencial.c -o pesquisa
./pesquisa
```

### Exercício 02

```bash
gcc 02_ordenacao_e_pesquisa_binaria.c -o ordenacao
./ordenacao
```

### Exercício 03

```bash
gcc 03_arvore_binaria.c -o arvore
./arvore
```

### Exercício 04

```bash
gcc 04_pilha.c -o pilha
./pilha
```

### Exercício 05

```bash
gcc 05_fila.c -o fila
./fila
```

## Objetivo

Praticar os conceitos de pesquisa, ordenação e estruturas
de dados utilizando a linguagem C.
